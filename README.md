# Acolhe

Site responsivo de apoio e informação sobre saúde emocional, desenvolvido com React,
TypeScript, Tailwind CSS e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

O Vite informa o endereço local no terminal.

## Build de produção

```bash
npm run build
npm run preview
```

O resultado da compilação é gerado em `dist/`. Os conteúdos são informativos e não
substituem atendimento de profissionais de saúde.
